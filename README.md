# FinRisk ABM Policy Simulation

This repository contains a research prototype for transaction risk policy design using Agent-Based Modeling (ABM), policy simulation, and feasibility analysis for hybrid LLM multi-agent extensions.

## Current scope

The current project focuses on:

- Synthetic transaction-risk simulation
- Policy comparison under fraud, false-positive, workload, and capacity trade-offs
- Net benefit evaluation for risk decision policies
- A static interactive HTML prototype for scenario exploration
- Initial token-cost feasibility analysis for LLM/hybrid multi-agent simulation

## Main folders

- `docs/`: research notes, theoretical framework, simulation design, and model evaluation notes
- `scripts/`: selected reproducible scripts for simulation, policy comparison, prototype generation, model experiments, and token cost feasibility
- `config/`: experiment assumptions and feasibility configuration
- `data/`: lightweight final comparison outputs only; raw reference datasets are not committed
- `reports/`: final report, prototype, and feasibility notes

## Important deliverables

- Final academic report: `reports/final/Bao_cao_De_an_FinRisk_Decision_Simulation_Final.docx`
- Interactive prototype: `reports/prototype/FinRisk_Decision_Simulation_Prototype_Final.html`
- Token-cost feasibility note: `reports/feasibility/token_cost_feasibility.md`

## Note on data

Large public raw datasets and intermediate simulation/model runs are intentionally excluded from Git. The repository tracks only lightweight final outputs needed to understand and reproduce the research direction.
